A host-specific setup

Preview PigeonStack before installation

The source reflects a personal Windows and PowerShell setup. Start with an isolated target to inspect the managed files and configuration without touching your live Codex home.

Do not copy the live-host commands on another machine. The default paths and some instruction files name the maintainer's directories. Adapt them before targeting another real Codex home.

Before you start

Check the current host requirements

  • The currently validated host is Windows with PowerShell.
  • The synchronization script requires Python 3.11 or newer.
  • Installing the plugin requires a compatible Codex CLI and an existing local marketplace registration that resolves pstack@personal.
  • Multi-agent work requires native child-agent tools and account access to the selected models.

Step 1

Clone the source

Run these commands in PowerShell from the directory where you keep source repositories.

git clone https://github.com/PigeonAI-Yang/pigeonstack.git
Set-Location pigeonstack

Step 2

Preview in a new sibling directory

These commands copy the managed files and merge the selected configuration in ../pigeonstack-preview-codex. The initial check normally exits with code 1 because that directory is empty. The final check exits with code 0 when the files and configuration align.

python scripts/sync.py check --codex-home ../pigeonstack-preview-codex --skip-plugin-install
python scripts/sync.py deploy --codex-home ../pigeonstack-preview-codex --skip-plugin-install
python scripts/sync.py check --codex-home ../pigeonstack-preview-codex --skip-plugin-install

What this preview checks

It checks the managed file copy and configuration merge in the isolated target. Invalid input or an operational error exits with code 2.

What it does not check

The preview skips plugin installation and installed-cache checks. It does not activate the plugin or rewrite machine-specific paths embedded in instructions.

For a nondefault target, keep --skip-plugin-install. The script rejects source and target paths that overlap.

Review the paths and settings

Maintainer host only

Deploy on the configured host

These commands target the maintainer's configured live Codex home. Review the intended changes and marketplace registration before running them.

Set-Location J:/PigeonYang/pigeonstack
python scripts/sync.py check
python scripts/sync.py deploy
python scripts/sync.py check

When deployment changes existing managed files, the script keeps backups under <codex-home>/backups/pigeonstack/. Plugin installation can fail after runtime files are written, so a failure is not an automatic rollback.
