按宿主环境适配

安装前先预览 PigeonStack

源码反映的是维护者在 Windows 与 PowerShell 上使用的配置。先把文件同步到隔离目录，检查受管理文件和配置，不要直接改动日常使用的 Codex 目录。

在其他机器上不要照抄真实宿主命令。默认路径和部分指令文件写有维护者的目录。将目标设为真实 Codex 目录前，请先完成适配。

开始前

检查当前宿主要求

  • 当前已验证的宿主是 Windows 和 PowerShell。
  • 同步脚本要求 Python 3.11 或更高版本。
  • 安装插件需要兼容的 Codex CLI，以及已注册并能解析 pstack@personal 的本地插件市场。
  • 多 Agent 工作需要宿主提供原生子 Agent 工具，并且账号可使用所选模型。

第 1 步

克隆源码

在 PowerShell 中进入你保存代码仓库的目录，然后运行：

git clone https://github.com/PigeonAI-Yang/pigeonstack.git
Set-Location pigeonstack

第 2 步

在新的同级目录预览

下面的命令会在 ../pigeonstack-preview-codex 中复制受管理文件并合并选定配置。首次检查通常因目录为空而以代码 1 退出。文件和配置一致时，最后一次检查以代码 0 退出。

python scripts/sync.py check --codex-home ../pigeonstack-preview-codex --skip-plugin-install
python scripts/sync.py deploy --codex-home ../pigeonstack-preview-codex --skip-plugin-install
python scripts/sync.py check --codex-home ../pigeonstack-preview-codex --skip-plugin-install

这项预览会检查什么

它检查隔离目录里的受管理文件副本和配置合并。参数无效或操作出错时以代码 2 退出。

这项预览不会检查什么

预览会跳过插件安装和已安装缓存检查。它不会激活插件，也不会改写指令中机器专属的路径。

目标不是默认目录时，保留 --skip-plugin-install。脚本会拒绝与源码目录重叠的目标目录。

在其他机器真实安装前

核对路径与设置

同步脚本的默认目标是 J:/Users/yangda01/.codex。全局规则、Codex 宿主说明和 poteto-agent.toml 角色文件中也有维护者的专属路径。

需要检查原因
scripts/sync.pyDEFAULT_HOME 指向维护者当前的 Codex 目录。--codex-home 参数不会改写指令中的所有路径。
AGENTS.md、pstack/CODEX.md 和 agents/poteto-agent.toml这些文件包含维护者机器上的源码或运行时路径。
config/workflow.toml部署前请检查模型默认值、Agent 设置、角色文件和插件启用项。
pstack/MODELS.md阅读模型 ID、首选路由、推理强度和子 Agent 创建约定。

脚本不会注册插件市场。在其他宿主真实安装前，先适配源码，并确认本地插件市场能解析 pstack@personal。

仅限维护者宿主

在已配置的宿主上部署

这些命令会写入维护者配置的真实 Codex 目录。运行前先审查目标改动与插件市场注册。

Set-Location J:/PigeonYang/pigeonstack
python scripts/sync.py check
python scripts/sync.py deploy
python scripts/sync.py check

部署覆盖现有受管理文件时，会在 <codex-home>/backups/pigeonstack/ 保存备份。插件安装可能发生在运行时文件写入之后，因此安装失败不会自动回滚。
